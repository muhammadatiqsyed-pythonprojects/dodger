# \# Dodger

# 

# A simple arcade game made with Pygame. Slide left and right to dodge

# the falling rocks. One hit and it's over, so see how long you can survive.

# 

# \## Status

# Work in progress.

# 

# \## How to play

# \- Keyboard: arrow keys or A/D to move

# \- Touch or mouse: press and drag to move

# \- Tap, click or SPACE to start and restart

# \- Your score is the number of seconds you survive

# 

# \## Run it locally

# 1\. Clone the repo

# 2\. Create and activate a virtual environment

# 3\. Install dependencies: `pip install -r requirements.txt`

# 4\. Run: `python main.py`

# 

# \## Built with

# \- Python

# \- pygame-ce

# \- pygbag (for the browser version)
